### -10 bounded persona-state adaptation - increment 1 `complete`; -10b see "Remaining executable work"
Delivered and deployed (PR #103; wording fix #108): closed style dimensions per persona (`response_depth`, `technical_depth`, `structure`, `intervention_style`) adapt through evidence -> candidate -> deterministic evaluation -> authority -> revision -> rollback. Structural guarantee against prompt self-modification: a revision can only select among fixed reviewed sentences, appended AFTER the untouched foundation prompt; no user text is ever stored in or rendered into a persona prompt. Authority as routing: explicit durable instruction promotes (household-wide unless it names a persona), feedback is a shadow-only correction (three consistent -> eligible awaiting ratification), one-off requests shape that turn only, reserved matters and `persist_turn=false` capture nothing; `/misumi/persona-state` API records the ratifying principal; `MISUMI_PERSONA_STATE=0` kill switch. Live-proven on a scratch instance with the real model (`evals/misumi-persona-state/2026-10-06-live-proof.md`): mean reply length about 66-70 words baseline vs 28 with a turn request vs 53-60 with the first durable wording (restart-persistent; restored after rollback with history kept); an eligible candidate stays inert until operator promotion (principal recorded), then effective, then rolled back; reserved matters not captured; an injected instruction captured only as style with nothing leaked. A direct experiment (`2026-10-06-style-placement-and-wording-experiment.md`) showed placement is irrelevant (~0.70 of baseline whether system, late or user) and WORDING decides the effect (shipped sentence 0.76, "at most two sentences" 0.47); the 0.47 wording was adopted (#108) and a stronger variant that told the persona to drop caveats was rejected on honesty/safety grounds. A second experiment (`2026-10-06-style-effect-experiment.md`) measured every fixed sentence against a mechanical metric: thorough 1.87x words, plain 0.65x long words, stepwise 100% numbered replies, brief 0.45x words worked; `proactive` produced NO next-step offers, `bullets` only 50% and `technical` only +19%, so those three were reworded and re-measured (offers 0% -> 67%, bullets 100%, technical +49%; #110); `prose` and `reactive` cannot be measured at a zero baseline. Latent bug found by the live demo and fixed (#104): `_named_persona_in_prompt` substring-matched persona `l`'s one-letter display name.
